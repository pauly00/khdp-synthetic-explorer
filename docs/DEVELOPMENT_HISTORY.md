# 개발 이력
## 목적
이 프로젝트는 공개 합성 의료데이터의 구성과 집계 규칙을 확인하기 위한 바이브코딩 시제품입니다. 화면을 빠르게 만드는 데서 끝내지 않고, CSV 등록·저장·조회·집계가 실제 데이터에 맞게 동작하는지 검증하는 것을 목표로 했습니다. KHDP는 데이터 제공 플랫폼이며, 개발 환경 자체를 뜻하지 않습니다.
## 진행 흐름
### 1. 승인정보 예시 검색 화면 제작
- **목적:** 공공데이터 연동 전 검색형 웹앱의 화면 흐름을 검토했습니다.
- **주요 요청:** 임상시험명·질환·승인번호·기관명 검색과 예시 목록·상세 보기를 구성했습니다.
- **반영 결과와 검증 범위:** 예시 데이터를 명확히 표시하는 검색 화면을 구현했습니다. 실제 공공데이터 API 연동은 범위에 포함하지 않았습니다.
### 2. KHDP 합성 데이터 기반 탐색 서비스로 확장
- **목적:** 승인정보 예시와 분리된 합성 환자 조건 조회 기능을 검증했습니다.
- **주요 요청:** 기본 진입 화면을 합성 데이터 탐색으로 바꾸고, 실제 환자 모집이나 임상 판단으로 오해되지 않게 했습니다.
- **반영 결과와 검증 범위:** 서비스 이름과 안내 흐름을 `합성 의료데이터 탐색`으로 정리하고, 기존 예시와 합성 데이터를 연결하지 않았습니다.
### 3. CSV 등록, 자료 연결, 조건별 고유 인원수 집계
- **목적:** 여러 CSV를 SQLite에 등록하고 person·condition_occurrence를 기준으로 고유 인원을 계산했습니다.
- **주요 요청:** 파일 검증, 추가 등록·전체 교체, 중복·충돌 구분, 기준일과 연령 조건 집계를 지원했습니다.
- **반영 결과와 검증 범위:** 청크 업로드와 서버 적재, 등록 이력, 집계 결과 CSV 내려받기를 구현했습니다. 집계는 동일 인물의 반복 기록을 한 번으로 셉니다.
### 4. 검사·약물·방문 및 관찰 기간 조회
- **목적:** 진단 외 기록을 개별 분석 화면에서 확인할 수 있게 했습니다.
- **주요 요청:** 검사·약물 코드별 목록, 검사 단위별 요약, 약물 날짜 품질, 방문 유형과 관찰 기간을 조회했습니다.
- **반영 결과와 검증 범위:** 등록된 자료가 없으면 409 응답과 화면 안내를 제공하며, 코드 사전에 없는 코드는 `명칭 확인 필요`로 표시합니다.
### 5. 대용량 업로드와 CSV 내려받기 오류 수정
- **목적:** 큰 CSV 등록 중 요청 크기 제한과 결과 다운로드 실패를 줄였습니다.
- **주요 요청:** 작은 조각 전송, 413 발생 시 조각 크기 축소 재시도, 화면 조회와 동일한 집계 함수를 이용한 CSV 생성이 필요했습니다.
- **반영 결과와 검증 범위:** 업로드 세션·조각 검사·완료 처리와 UTF-8 BOM CSV 응답을 구현했습니다. 실제 운영망의 요청 제한값은 이 코드만으로 보장되지 않습니다.
### 6. 사용 안내와 로딩 상태 개선
- **목적:** 처음 방문한 사람이 데이터 목적과 화면 사용법을 이해하도록 했습니다.
- **주요 요청:** 화면별 도움말, 모달 키보드 동작, 빈 상태·오류·재시도·지연 안내를 정리했습니다.
- **반영 결과와 검증 범위:** 도움말은 현재 화면별 설명을 제공하고 Esc와 닫기 후 초점 복귀를 처리합니다. 모든 외부 배포 환경의 접근성 평가는 별도 수행하지 않았습니다.
### 7. 검사 및 약물 조회 성능 개선
- **목적:** 대용량 measurement·drug_exposure 자료에서 목록이 비어 보이거나 오래 기다리는 문제를 해결했습니다.
- **주요 요청:** 실제 API·DB·SQL을 확인하고 서버 페이지네이션 및 로딩 상태를 적용했습니다.
- **반영 결과와 검증 범위:** 코드별 요약 테이블과 20개 단위 목록 조회를 사용합니다. 요약은 검사·약물·코드 사전 적재 후 다시 계산됩니다.
### 8. Spring 및 H2 이전 시험 후 취소
- **목적:** 기존 FastAPI·SQLite를 다른 서버 및 파일 DB로 옮길 수 있는지 별도 공간에서 시험했습니다.
- **주요 요청:** Java 실행, WAR, H2 지속성 및 이전 가능성을 확인하되 기존 서비스와 데이터를 보존했습니다.
- **반영 결과와 검증 범위:** 이전이 완결되지 않아 취소했으며, 현재 실행 경로는 React·Vite·FastAPI·SQLite 구성입니다. 시험 자료는 `archive/retired-migration/`에 분리되어 있고 서비스가 사용하지 않습니다. 세부 시험 결과와 기록 간 불일치는 [Java·Spring·H2 이전 시험 기록](MIGRATION_TROUBLESHOOTING.md)을 참고하세요.
## 현재 상태와 범위
현재 API와 화면은 FastAPI 및 SQLite를 사용합니다. 미지원 자료의 전용 분석 화면, 외부 공공데이터 API 연동, 실제 환자 모집·의료 판단 기능은 구현 완료로 보지 않습니다.
