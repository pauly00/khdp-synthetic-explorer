# 사용자 안내

## 시작하기

1. **서비스 안내**에서 시제품의 목적과 제한을 확인합니다.
2. **데이터 개요**에서 어떤 CSV가 등록되었는지와 저장 행 수를 확인합니다.
3. 필요한 자료가 없다면 **데이터 관리**에서 해당 CSV를 등록합니다.
4. 진단 분석, 검사 기록, 약물 기록, 방문 및 관찰 기간, 조건별 집단 비교 화면에서 등록 내용을 조회합니다.

이 서비스의 결과는 합성 데이터 집계입니다. 실제 환자를 찾거나 임상적 판단을 내리는 용도로 사용하지 않습니다.

## 데이터 관리

- 자료별로 CSV 파일을 선택한 후 **선택한 파일 등록** 또는 **추가 등록**을 누릅니다.
- **전체 교체**는 해당 자료의 기존 행을 새 파일로 바꾸는 작업이므로 원본을 확인한 뒤 사용합니다.
- 업로드 중에는 전송한 바이트와 조각 수가 표시됩니다.
- 전송 중 취소할 수 있습니다.
- 완료 화면에서 읽은 행, 신규 저장, 동일 중복, 내용 충돌, 검증 오류, 전체 저장 행 수를 확인합니다.

파일이 크면 전송과 적재 시간이 오래 걸릴 수 있습니다. 화면을 닫기보다 진행 상태를 기다리고, 실패 메시지가 나타나면 원인과 재시도 버튼을 확인하세요.

## 검색과 조회

### 진단 분석

진단명 또는 코드로 검색합니다. 목록 행을 선택하면 해당 정확한 코드의 상세 화면으로 이동합니다. 관련 코드나 하위 코드는 자동으로 합치지 않습니다.

### 검사 기록과 약물 기록

검사명·약물명 또는 코드를 검색하고 정렬을 선택합니다. 목록은 한 번에 20개 항목을 보여 주며, 아래의 **더 보기**를 누르면 다음 목록을 가져옵니다.

검사 행을 선택하면 단위별 기록 수와 숫자 결과 요약을 확인할 수 있습니다. 약물 화면은 시작일·종료일 누락, 날짜 형식 오류, 종료일 역전 수를 함께 표시합니다.

### 방문 및 관찰 기간

방문 유형별 기록·고유 인원과 연도별 기록을 확인합니다. 관찰 기간 CSV가 있으면 평균 일수와 날짜 오류도 표시합니다.

## 조건별 집단 비교

1. 진단명을 검색해 정확한 코드 하나를 선택합니다. 선택하지 않으면 전체 등록 인원을 대상으로 합니다.
2. 기준일을 지정합니다. 해당 날짜 이후의 진단 기록은 제외됩니다.
3. 필요하면 최소·최대 나이를 입력합니다. 비워 두면 그 방향의 제한을 적용하지 않습니다.
4. **조회**를 눌러 조건 적용 전후의 고유 인원수를 확인합니다.

조회 뒤 조건을 바꾸면 기존 결과와 현재 입력이 달라집니다. 이때는 다시 조회한 뒤 파일을 내려받으세요.

## CSV 내려받기

조건별 집단 비교의 **집계 결과 CSV 내려받기**는 마지막으로 성공한 조회와 같은 조건으로 CSV를 만듭니다. 파일에는 기준일, 선택 진단명·코드, 최소·최대 나이, 진단 조건 인원, 연령 조건 적용 후 인원, 제외 인원이 들어갑니다.

## 자료실

자료실은 별도로 등록한 데이터 설명서 README.md와 LICENSE.txt 원문을 읽고, 메모를 저장하는 공간입니다. 프로젝트 루트의 개발자용 README와 `docs/` 문서는 자동으로 표시되지 않습니다.

## 도움말

오른쪽 위 `?` 버튼을 누르면 현재 화면의 목적, 사용 방법, 읽는 법, 알 수 없는 범위를 확인할 수 있습니다. Esc 키 또는 닫기 버튼으로 닫을 수 있습니다.

오류별 점검은 [문제 해결](TROUBLESHOOTING.md)을 참고하세요.
